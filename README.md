# Simple-Work-Link

シンプルで使いやすい **勤怠管理 & 各種申請システム** です。  
現場スタッフと管理者の双方が直感的に使えるデスクトップアプリケーションとして設計されています。

## ✨ 主な機能

### 🏗 現場ユーザー向け

| 機能 | 説明 |
|------|------|
| **ワンタッチ打刻** | 大きなボタンで出勤・退勤をワンタップ記録。GPS情報も自動取得 |
| **各種申請** | 勤怠（有給・欠勤等）、金銭（交通費・消耗品等）、その他（相談・報告等）を統一フォームから申請 |
| **定型文テンプレート** | カテゴリに応じた理由テンプレートで入力の手間を削減 |
| **申請履歴** | 自分の申請のステータス（未承認・承認済・却下）をリアルタイムで確認 |
| **通知機能** | ログイン時に申請結果（承認/却下）を自動通知 |

### 🖥 管理者向け

| 機能 | 説明 |
|------|------|
| **勤怠管理** | 全スタッフの打刻一覧を確認。9:15以降の遅刻は赤字でアラート表示 |
| **打刻修正** | 打刻時刻やステータスを直接編集可能。修正履歴も自動記録 |
| **ユーザー管理** | 新規ユーザー追加、権限（現場/管理）の設定、有効/無効の切り替え |
| **申請管理** | 申請の承認・却下。却下時は定型理由の選択 or 「その他」で手書き入力が可能 |

## 📷 画面イメージ

```
ログイン画面 → 現場ホーム（出勤/退勤ボタン） → 各種申請フォーム
                     ↓
              管理ダッシュボード（勤怠管理 / ユーザー管理 / 申請管理）
```

## 🚀 セットアップ

### 前提条件

- Python 3.10 以上
- pip（Pythonパッケージマネージャー）

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/nanashinogonbe2026/SimpleWorkLink.git
cd SimpleWorkLink

# 依存パッケージをインストール
pip install -r requirements.txt
```

### 起動

```bash
python src/main.py
```

## 📁 プロジェクト構成

```
SimpleWorkLink/
├── requirements.txt          # 依存パッケージ
├── attendance.db             # SQLiteデータベース（自動生成）
└── src/
    ├── main.py               # アプリのエントリーポイント・ルーティング
    ├── database.py           # データベース操作（CRUD・認証・統計）
    └── ui/
        ├── login_view.py     # ログイン画面
        ├── home_view.py      # 現場ホーム画面（打刻・通知）
        ├── requests_form.py  # 各種申請フォーム・履歴
        └── admin_dashboard.py # 管理ダッシュボード
```

## 📊 データベース構造

| テーブル | 用途 |
|----------|------|
| `users` | ユーザー情報（氏名・ロール・ログイン情報・有効/無効） |
| `records` | 打刻記録（出勤/退勤・タイムスタンプ・GPS・ステータス） |
| `requests` | 各種申請（カテゴリ・内容・金額・承認状態・却下理由） |
| `modification_logs` | 打刻修正の履歴ログ |

## ⚠ 注意事項

- 本アプリはポートフォリオ・プロトタイプ用途です
- パスワードは SHA-256 で保存していますが、本番環境では `bcrypt` や `PBKDF2` の利用を推奨します
- GPS位置情報は現在モック値を使用しています
- ファイル添付機能は現在無効です
